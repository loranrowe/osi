Package Structure

osi/

Class Hierarchy — 11 个 Pydantic 模型

SemanticModel
name, description, ai_context, datasets[], relationships[], metrics[], custom_extensions[]
Dataset
name, source, primary_key[], unique_keys[][], description, ai_context, fields[], custom_extensions[]
Relationship
name, from, to, from_columns[], to_columns[], ai_context, custom_extensions[]
Metric
name, expression, description, ai_context, custom_extensions[]
Field
name, expression, dimension?, label?, description?, ai_context, custom_extensions[]
AIContext
instructions?, synonyms[], examples[] — 可 str 也可 dict
CustomExtension
vendor_name, data: str
FieldExpression / DialectDef / DimensionMeta
