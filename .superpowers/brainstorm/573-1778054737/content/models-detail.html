Core Models Detail — 关键设计决策

每层模型的字段设计和校验规则

1. 辅助模型（叶子节点）

DialectDef
dialect: Dialect (enum: ANSI_SQL|SNOWFLAKE|DATABRICKS|MDX|TABLEAU)
expression: str (SQL表达式)
DimensionMeta
is_time: bool = False
AIContext
instructions: str | None
synonyms: list[str] = []
examples: list[str] = []
CustomExtension
vendor_name: Vendor (enum: COMMON|SNOWFLAKE|SALESFORCE|DBT|DATABRICKS)
data: str (JSON字符串，暂不解析)

2. 核心业务模型

Field
name: str ★必填
expression: FieldExpression ★必填
dimension: DimensionMeta | None
label / description / ai_context / custom_extensions
Dataset
name: str ★ | source: str ★
primary_key: list[str] = []
unique_keys: list[list[str]] = []
fields: list[Field] = []
description / ai_context / custom_extensions
Relationship
name / from / to: str ★必填
from_columns / to_columns: list[str] ★必填
⚡ 校验: len(from_columns) == len(to_columns)
Metric
name: str ★ | expression: FieldExpression ★
description / ai_context / custom_extensions

3. 顶层容器

SemanticModel
name: str ★ | datasets: list[Dataset] ★
description / ai_context
relationships: list[Relationship] = []
metrics: list[Metric] = []
⚡ 额外的 model_validator: 检查 relationship.from/to 引用的 dataset 是否存在

特殊处理点

ai_context 双类型 字段接受 str | dict | None，使用 field_validator 统一转为 AIContext 对象
expression 数组兼容 Metric 的 expression 在 spec 示例中有时是数组有时是对象，parser 层做归一化
custom_extensions.data 保持为 JSON 字符串，不做解析。提供 .parsed_data property 按需解析
model_config extra="forbid" — 严格模式，未知字段报错，避免拼写错误悄悄被忽略
